tumesalista.pe - CÓMO EJECUTARLO EN LOCALHOST
=============================================

1. Instala Node.js (versión LTS) desde https://nodejs.org
   Comprueba en una terminal:  node -v   (debe salir v18 o mayor)

2. Descomprime el zip y abre la carpeta "proyectoweb2026" en VS Code
   (Archivo > Abrir carpeta). Abre una terminal: Terminal > Nueva terminal.

3. Escribe (solo la primera vez):
     npm install

4. Para iniciar:
     npm start
   Se abre solo en  http://localhost:3000
   Para detenerlo: Ctrl + C en la terminal.

FORMULARIOS QUE FUNCIONAN
  - Reservar mesa (DNI, nombres, apellidos, celular, correo) -> /#/reservar
  - Contacto con cada restaurante -> /#/contacto
  - Acceso restaurantes (login) -> /#/admin
  - Panel: agregar/editar platos y precios
  - Panel: crear/pausar promociones
  Todo se guarda en el navegador (localStorage): si recargas, sigue ahí.
  Lo que agrega el restaurante aparece al instante en la carta pública.

USUARIOS DE RESTAURANTE
  admin.nonna / nonna123      admin.norteno / norte123
  admin.sakura / sakura123    admin.brasa / brasa123

PROBLEMAS FRECUENTES
  - "npm no se reconoce": instala Node.js y reinicia VS Code.
  - PowerShell dice "scripts deshabilitados": usa la terminal "cmd"
    o ejecuta una vez: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  - "Port 3000 is already in use": responde "Y" para usar otro puerto.
  - Errores raros: borra la carpeta node_modules y vuelve a hacer npm install.
  - Para empezar con datos limpios: en el panel, "Restaurar datos de ejemplo".

Solo verlo sin instalar nada: doble clic en ABRIR-DEMO.html
